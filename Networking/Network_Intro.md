# Data Communication
When we communicate, we are sharing information.  The term telecommunication, which includes telephony, telegraphy, and television, means communication at a distance (tele is Greek for "far").

The word <B>Data</B> refers to information presented in whatever form is agreed upon by
the parties creating and using the data.

Data-flow: simplex, half-duplex, and full-duplex

### <u>Network</u>
A network is a set of devices (often referred to as nodes) connected by communication
links. A node can be a computer, printer, or any other device capable of sending and/or
receiving data generated by other nodes on the network.
